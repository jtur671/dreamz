# TikTok Profile Setup — @dreamz_journal

> Manual checklist. Do these steps in the TikTok app.

## 1. Switch to Business Account

Settings > Account > Switch to Business Account > Select **Education** category

This unlocks:
- Clickable link in bio (no 1,000 follower requirement)
- Analytics dashboard
- Commercial music library

## 2. Profile Picture

Use the Dreamz app icon (`assets/icon.png`).

Save it to your phone's camera roll, then: Edit Profile > Change Photo > Choose from Library

## 3. Bio

Copy-paste this exactly:

```
Your dreams, divined. ✨ Dream journal with mystical AI readings
```

(63 characters — under the 80-char TikTok limit)

## 4. Link

Edit Profile > Website:

```
https://apps.apple.com/app/id6760150023
```

App is live — link directly to the App Store. (The landing page at https://dreamz-journal.com/ is still useful for cross-platform traffic and the Android waitlist, but the primary conversion goal from TikTok is an iOS install.)

## 5. Display Name

Set to: **Dreamz**

## 6. Username

Already set: **@dreamz_journal**

## Done

Your profile is now live and link-ready. Next: create and post your first video.
